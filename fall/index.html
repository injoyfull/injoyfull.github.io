Core Method

오늘의 꾸러미

완성 예시도, 순서도 드리지 않습니다. 그날의 재료 한 꾸러미만 건넵니다.
어떤 날은 활짝 열어두고, 어떤 날은 궁금해서 열어보고 싶게 닫아둬요.
“오늘의 꾸러미예요. 마음껏 열어보세요.”

초등학생(8세 이상) · 상시 · 예약제

크리디패스 — 나만의 작업실 이용권

키즈카페나 레고방처럼 예약하고 방문해서, 인조이풀 작업실을 아이의 개인 작업실로 자유롭게 이용하는 패스예요.

초등학생이 되면 아이들의 하루는 학원으로 채워집니다. 자기 안의 예술성을 스스로 발견해 보는 경험 없이 지내다 보면, 감각의 스위치가 하나둘 내려가 버려요. 크리디패스는 그 스위치를 아이가 직접 다시 올려 보는 시간이에요.

인조이풀은 손으로 직접 만드는 메이커 방식의 작업실이에요. 다양한 재료(루즈 파트)로 오늘 하고 싶은 것을 아이가 직접 고릅니다.

  • 점토점토로 만들기
  • 샌드보틀샌드보틀 꾸미기
  • 콜라주콜라주 · 믹스미디어 작업
  • 코딩레고 · 큐브로이드 코딩
  • 메이커목공 · 글루건 작업

고른 활동 안에서 재료와 도구를 마음껏 쓰며 스스로 관찰하고, 질문하고, 선택해요. 그동안 아이는 자기 작업의 기획자이자 개발자, 연구자가 됩니다.
